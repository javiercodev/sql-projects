# sql-projects

SQL exercises organized by topic. Built as part of my studies in Web Application Development (DAW).

## Contents

| Folder | Topic |
| --- | --- |
| [`erd`](./erd) | Entity-relationship diagrams (database design) |
| [`query_execution`](./query_execution) | Query execution (querying and manipulating data) |
| [`relational_database_creation`](./relational_database_creation) | Relational database creation (tables, keys, constraints) |

## How to run an exercise

You'll need a SQL database engine installed, such as [MySQL](https://dev.mysql.com/downloads/) or [MariaDB](https://mariadb.org/download/).

```bash
git clone https://github.com/javiercodev/sql-projects.git
cd sql-projects/<folder>/<exercise>
```
Then open the `.sql` file in your SQL client and run it. Exercises usually include diagrams (`.png`) or draw.io files (`.drawio`) of the database design.
